# D–D loop upper-bound model 2.0-alpha-1

Воспроизводимый ноутбучный расчёт строгой оптимистической верхней границы энергетической обратной связи в D–D-петле.

Модуль отвечает на узкий вопрос: может ли энергия продуктов D–D-реакций при заданных плотности и времени удержания восстановить энергетический запас дейтронного хвоста, вызвавшего эти реакции. Это скрининговая модель, а не самосогласованная симуляция плазмы.

## Зафиксированный результат

Для исходного режима расчёт даёт:

- решение: `NO_GO_SELF_SUSTAINING_DD_AT_CURRENT_PARAMETERS`;
- строгую верхнюю границу `K_loop,max = 4.162311873836316e-10`;
- максимум при энергии одного дейтрона около 100 кэВ и геометрии встречных равных пучков;
- требуемое произведение `n_D τ = 7.784135591487431e20 м⁻³·с` для формального достижения `K = 1` в той же идеализированной модели.

Граница намеренно завышена: в режиме `absolute_upper` предполагаются 100-процентное удержание всей энергии продуктов, включая нейтроны, и 100-процентное преобразование этой энергии в новое поколение хвоста. Поэтому добавление реальных потерь может только уменьшить коэффициент.

Отрицательный результат относится к гипотезе самоподдерживающейся D–D-петли при принятых параметрах. Он не опровергает отдельно исследуемую внешне питаемую архитектуру формирования хвоста.

## Быстрый запуск

Требуется Python 3.10 или новее. Расчётный модуль использует только стандартную библиотеку.

```bash
python -m unittest discover -s tests -v
python dd_loop_upper_bound_alpha1.py --output-dir results/local
```

После запуска создаются:

- `alpha1_summary.json` — полное машиночитаемое резюме;
- `alpha1_table.csv` — значения для контрольных энергий и геометрий.

Контрольные результаты находятся в каталоге [`results/reference`](results/reference).

## Физические и численные ограничения

- Модель не является EM-PIC-, Vlasov- или Fokker–Planck-расчётом.
- Она не моделирует формирование хвоста, самосогласованное поле, торможение продуктов и пространственный транспорт.
- Геометрии `beam_target` и `head_on_equal_beams` являются идеализированными предельными сценариями.
- Низкоэнергетическая часть скана может выходить за рекомендуемую область параметризации Bosch–Hale; найденный максимум расположен внутри рабочего диапазона.
- Результат нельзя трактовать как проектную оценку реактора или экспериментальной установки.
