# Changelog

## 2.0-alpha-1 — 2026-09-05

- Реализована параметризация двух ветвей D–D по Bosch–Hale.
- Добавлены идеализированные геометрии «пучок–мишень» и «два встречных равных пучка».
- Добавлен энергетический регистр и расчёт `K_loop,max`.
- Добавлены сканирование по энергии, анализ чувствительности и машиночитаемый вывод.
- Добавлены шесть автоматических тестов.
- Зафиксированы отрицательные энергетические ворота для самоподдерживающейся D–D-петли при исходных параметрах.
