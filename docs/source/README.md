# Исходные документы

В каталоге сохранены три Word-документа, использованные при формировании репозитория:

- техническая спецификация алгоритма версии 2.0;
- аналитический отчёт по отрицательному результату 2.0-alpha-1;
- документ с зафиксированными листингами расчётного модуля и тестов.

Исполняемыми и удобными для контроля версий источниками являются файлы в корне репозитория и каталоге `tests`. Контрольные суммы извлечённых листингов совпадают с указанными в исходном документе.
